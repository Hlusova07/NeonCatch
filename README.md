# NEON CATCH

## Описание проекта
NEON CATCH — настольная игра на Java с графическим интерфейсом Swing.
Игрок управляет платформой с помощью мыши и ловит отскакивающий мяч.
За каждое успешное попадание начисляется очко. Если игрок пропускает мяч,
он теряет одну жизнь. Всего доступно три жизни.

## Управление
- SPACE — начать игру
- Мышь — перемещать платформу
- N — начать новую игру
- ESC — выйти из игры

## Использованные технологии
- Java 21
- Java Swing и AWT
- Обработка событий мыши и клавиатуры
- Отдельный поток игрового цикла
- Объектно-ориентированное программирование

## Структура проекта
- Main.java — запуск приложения и создание окна
- GamePanel.java — интерфейс, отрисовка и игровая логика
- GameEngine.java — игровой цикл в отдельном потоке
- GameConstants.java — игровые параметры и цвета

## Запуск
Из корневой папки проекта выполните:

javac -d out src/Main.java src/GameConstants.java src/GameEngine.java src/GamePanel.java
java -cp out Main
